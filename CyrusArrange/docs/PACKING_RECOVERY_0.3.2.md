## Ownership, bounds and failure before implementation

Keep the ordinary initial solve. For ordinary Quantity underfill with new unlocked
placements, try at most four deterministic alternate packing domains. Each trial
restarts from the authored previous/protected/selective-region inputs, so it may
rearrange newly proposed unlocked objects. It never uses an earlier trial as
protected input. The same receiving query and explicit obstacle scopes validate
every complete final pose. Required-source order and minimum reservations remain.

Alternate first proposals use boundary-biased centers from region and source
bounds; these are proposals only. Source contact/compound collision, supported
edges, overhead and spacing still decide acceptance. Original/random/fit settings
remain unchanged. An alternate internal seed derives from the saved seed and a
fixed attempt domain; the artist's saved seed is unchanged and repeats the same
full solve. No new UI, schema, persisted policy or cache is introduced.

The public C++ command owns the best copied numeric result and at most one trial.
Release the first solve's input/collider/obstacle scratch before a trial starts;
do not recursively retain two full solver workspaces. A best result retains at
most 10,000 Placement values plus existing bounded composition/report metadata.
The trial owns its normal bounded workspace/output. Failure-recorder maps contain
copied bounded representatives and move with the selected result. No copied mesh,
query or host reference is retained for recovery. Cache invalidation is unchanged.

Charge all generation work, candidates and rejected queries across every attempt
to the existing command limits; admit trials only with sufficient remaining
allowance relative to the initial solve. Sum probe/work statistics, while accepted,
kept, fitted and missing minimum counts describe the winning complete result.
Accept a replacement only if total placed and required fulfillment never worsen,
with at least one improving. Equal alternatives retain the initial layout.

Defer fit advice during trial generation. Prepare advice once for the winning
underfilled result, with its copied failures and final accepted objects, using
the existing separate bounded advice allowance. Preserve ordinary Fill's regional
seed/independence behavior and explicit book-row composition. This change targets
the reproduced ordinary Quantity packing failure; full goal acceptance remains.

No partial trial is published. Unexpected validation errors or genuine command
work/candidate exhaustion propagate to the host's existing atomic retention of
the previous complete arrangement. No broad exception swallowing or limit increase.
Generate remains one host transaction; Undo/reopen/source preservation semantics
are unchanged. No artist profile or original model repair occurs.

## Implemented behavior and evidence

Ordinary Quantity uses the unchanged first solve, then at most four alternate
domains only when underfilled and new unlocked choices exist. The first usable
proposal in a recovery domain moves toward a region boundary and tries permitted
yaws; subsequent candidates still use the ordinary complete validator. A trial
replaces the best result only when placed count and minimum fulfillment do not
worsen and at least one improves. Fill and explicit book-row generation retain
their original paths. The same command's work/candidate allowance covers all
trials. Fit advice runs once, after choosing the final result.

The maintained regression first failed against preserved native10 after 5,333
space-workflow checks, with both literal full-size poses already physically
validated. Its receipt is `build/packing-recovery-native-repro01/receipt.json`.
The first corrected SDK build passed twenty suites. Its complete captured-source
diagnostic changed seven underfilled seeds to **zero of sixteen** without changing
original dimensions. The final expanded build `build/native-032-packing-recovery02`
passes twenty suites, including **5,468 space-workflow checks**, with no compiler
warnings. It freezes 180 source inputs; schemas and artist UI are unchanged.

The actual normal Max2027 fixture in `build/host-032-packing-recovery03` passes
**64 checks** with all five identity/private-profile guards. It exercises sixteen
seed pairs through mounted Modify Generate, original dimensions, complete source
materials and every mapped UV corner, fresh seed, protected placement, explicit
obstacle underfill, minimum copies, 80–110% random scale, Undo/Redo and save/reopen.
The saved artist seed remains the authored seed even when an alternate internal
domain wins. It observed 3,031ms for sixteen seed pairs, including scripted
appearance checks; this is not a general latency or cache-hit claim.

`independent-packing-recovery.json` proves five actual-mesh cases and rejects five
invalid controls. Every published appliance retains all 802 vertices, 1,508 faces

15mm. The explicit-obstacle case deliberately preserves 2 requested / 1 placed /
1 unfilled; only that actual single output is physically proved there. This is
not a claim of two-copy capacity in occupied space.

The native02 complete captured Table06/source diagnostic also places both literal
