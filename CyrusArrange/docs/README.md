Cyrus Arrange is an interior arrangement plugin for 3ds Max 2027. Native C++ owns geometry, asset data, placement and scene state; MAXScript presents the artist controls. All distances in the controls are millimetres.

**Preserved delivery status:** **0.2.0 was qualified for its documented Max 2027 workflow**, including actual isolated MZP installation and automatic startup. See [validation](RELEASE_VALIDATION_0.2.0.md), the [installer](../dist/CyrusArrange-0.2.0/CyrusArrange-0.2.0-Max2027.mzp), [matching source/examples](../dist/CyrusArrange-0.2.0/CyrusArrange-0.2.0-Source-and-Examples.zip) and [ready scene guide](../examples/simple-0.2.0/README.md). Earlier packages, receipts and example originals remain preserved.
