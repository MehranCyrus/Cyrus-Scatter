The native icon and the Cyrus Arrange modifier present one Document through an
off-scene MAXScript Custom Attribute. Five inline rollouts replace the main,
Props and Advanced dialogs: Cyrus Arrange, Props, Scale, Keep clear,
Path. The first two start open; optional sections start collapsed. Path includes
two-way and variation fields, compacting rows and showing only relevant inputs.
No authored state is stored in the presentation CA. Legacy normal entry actions
focus Modify. The compact path interface passed the mounted Max checks recorded
below; the whole release remains unqualified.

The normal sequence is receiving geometry, original props, quantity or Fill,
optional scale range, Generate. Quantity is a total across receiving surfaces.
Generate stages the visible placement and scale values with the solve and output
publication in one native transaction; a failed draft retains accepted state and
output. Generate chooses a fresh seed by default. Repeat seed reveals an exact
Integer64 entry and reproduces a saved variation. Source/library binding commands
are explicit Undoable edits; changing a spinner is only a draft until Generate.

Props appear inline. Pick props accepts multiple viewport picks and right-click
finishes. Add selected props works with a pinned Modify stack. The reusable group
command copies picked components into one source group without changing originals.
Remove prop + copies explicitly removes that library entry and its generated
outputs. All intake/copy validation remains native and bounded. Viewport picker
interaction requires its own acceptance; testing the shared command does not
prove the mouse interaction.

The [native fit feedback increment](FIT_FEEDBACK_0.3.2.md) adds a contextual
explanation and Show fit space / Use checked size inside Props. One source is
selected automatically. The extra controls occupy space only when its last
Generate left copies unplaced. The native highlight preserves selection, scene
nodes and any separate Preview. The size action edits the visible scale draft;
Generate applies it. Relevant input changes, time/units, Undo and load invalidate
the transient report. The complete current pair passed 117 workflow plus 31 fit
checks in actual mounted Max, with schema7 and transient CA8. These are development
checks, not final installer or mouse/pixel qualification.

The [inline Keep clear increment](KEEP_CLEAR_0.3.2.md) brings native independent
obstacles and the optional approach check into the same fourth rollout. Picking
or removing a reference is an explicit Undoable edit; the approach checkbox is a
draft committed atomically with Generate. Collision quality and support sampling
remain automatic. The native scope validator owns group/role admission and stale
row rejection. No additional rollout or popup is introduced. Its complete exact
pair host qualification is tracked in that report; earlier counts below retain
their original source scope.

The new native creation command has no category argument. Native helper creation
is public in Helpers > Cyrus, and an explicit Create Cyrus Arrange macro creates
and selects the owner in Modify. Receiver binding validates role overlap without
solving. Initialization avoids duplicate native modifiers. Automatic inspection
sampling uses evaluated receiver bounds, refreshed prop footprint dimensions and
an explicit cell budget, with capacity reserved for multiple support levels. Full
placement queries still validate the final candidate. Automatic coarsening can
miss narrow features in enormous assemblies; it is not exact continuous geometry
recognition or an unlimited inspection budget.

An instance binding serial, native owner GUID and active CA guard command entry.
Pick operations recheck the captured owner after picking. Retired views cannot
write into a newly selected arrangement, and a late old close cannot clear the
active view. Merely opening Modify does not inspect geometry or solve.
