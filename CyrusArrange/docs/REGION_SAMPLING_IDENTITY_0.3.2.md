# Sampling and saved region identity

## Problem and evidence

A region's stable identity includes its source keys, supported-cell centres and
cell size. Registry matching is deliberately exact. A new cell size therefore
retires the old IDs even if the receiving mesh is unchanged. Stored region
semantics belong to those IDs; labels, exclusions and front direction are
authored state, not furniture inference.

Current Generate automatically chooses a grid from receiver bounds and source
base sizes. On the actual released TV scene, the saved25mm grid becomes9mm. The
protected row still refers to its original region8, but only fresh IDs remain.
The message `Protected row requires its current regional front policy` means
that the region policy is missing in this case; it is not evidence of a rotated
front. The new analysis did not infer a different front vector.

The release06 migration host passes235 checks through exact schema3/4 load,
save/reopen, all original poses/groups, protection Undo/Redo and invalid-draft
retention. Explicit ordinary generation then fails on that missing reference.
The failed receipt remains preserved. The current-authored legacy fixture did
not expose this older saved lattice.

Bulk release06 also reports five physical-board assertions failed while its
geometry, material, seed and collision assertions pass (121 passes overall).
That fixture analyzes at25mm and explicitly excludes every receiving region
except its chosen top. Automatic replacement of its region IDs can discard that
authored selection. The next fixture must log actual output heights, bounds,
accepted grid and edge gap to identify each physical failure independently.

## Intended ownership and failure contract

Preserve the current accepted cell size during automatic generation when stable
region identity is required by protection, selective scope or nondefault saved
RegionSemantics. A field-exact comparison against the default semantics identifies
authored state without inventing a new persisted flag. Descriptive category
metadata remains descriptive; preserving it must not restore category eligibility
or count restrictions.

Neutral unconfigured regions still permit automatic grid selection. An explicit
raw inspection-setting change remains explicit and may retire incompatible IDs.
Do not add nearest-region matching or silently reassign protected rows.

Keeping the lattice does not reuse stale geometry. Recapture receivers, reconcile
exact shapes, recalculate clearance, and perform full physical validation of
protected and new placements. Changed source identity, geometry, unsupported
bases, holes, overhead or changed front policy must still fail safely where
applicable. Work/cell admission limits remain authoritative. Failure keeps the
previous complete settings, seed, protected relationships and output references;
one Undo must restore a successful transition completely.
