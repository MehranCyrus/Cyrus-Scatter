# Mesh channel density qualification

These are private **Max 2027** fixtures for 0.82.4. Run only through
`tools/eleven_phases/request.py` in a redirected disposable host. Never execute
them in the normal artist profile. The maintained
[handoff](../../docs/plans/eleven-phase-roadmap/MESH_MASK_0824.md) pins source,
native modules, receipts, fixture failures and evidence limits.

The campaign lives under `build/mesh-mask-0824-20261015-01`; final script staging
is `script-03`. `tools/eleven_phases/launch.py` verifies its sources and binaries
before a fresh owned launch. Do not reuse a stale candidate after source changes.

Order for the main `foundation-roadmap-meshmask-*` host:

1. `qualification.py`: channel/components, independent thinning, complete row
   equality, invalid-input retention, Paint/maps/slope/Relax, copy and reopen.
2. `edit_undo.ms`: outside Python's hold, real Undo/Redo and Edit dormancy.
3. `live.py <folder>`: stages actual callbacks using `live.ms`; observer waits
   happen outside the host thread. Diagnose a timeout before submitting more.
4. `ui.ms`: starts from the previous Edit/Live fixture and tests native curve
   Apply/reopen/captured owner, Preview/Hide and Paint hover properties.
5. `producers.py`: resets the scene; actual Data Channel Curvature to numbered
   channels/vertex colors and VertexPaint modifier passthrough.
6. `heavy.py`, then `quiet.ms` twice: 200,000 candidates, 180,200 faces, receiver
   cache reuse and a five-second idle window. Wait for `mesh-quiet-ready.txt`
   between requests; preserve the stress receipt before running the mountain.
7. `mountain_inspect.py`, `mountain.py`, then `quiet.ms` twice: only the
   hash-verified owned scene from `mountain/source.json` is loaded. Working saves
   use a distinct path. `mountain_ui.ms` opens/closes its native curve dialog for
   inspection. Preserve and rehash the artist's original file.
8. `final_identity.py`: verify the loaded script fingerprint and successor
   snapshot. Also verify the four loaded module paths/hashes externally.

`interactions.py <folder>` runs `interactions.ms` in the owned regression host
after inherited P01-P05 qualification. It covers map-face seams, Band ownership,
bounded accepted-target refill and real Data Channel animation. In MaxScript,
Vertex Output's class ID needs the positive 64-bit literal `2882382387L`;
the signed hexadecimal literal silently fails to create that operator.

`producer_probe.py`, `interactions_probe.ms`, `live_probe.py`, `live_reset.ms`
and `ui_verify.py` are diagnostics, not extra acceptance passes. Keep failed
request receipts. Explicit same-event map edits use Update/`refreshAll`;
`evaluateProcedural` alone does not consume deferred geometry notifications.

The original native reader supports channels 0..99 and one scalar component.
These fixtures do not certify physical VertexPaint strokes, every asset/renderer,
presented viewport FPS, tablet/DPI combinations or sustained sessions.
