# Cyrus Scatter 0.44

Fixes the Edge Border Offset inward, Jitter along, and Jitter across UI handlers calling selectedStroke before MAXScript has bound the function. Handlers are now declared after the rollout helper functions, in every layer panel.

This is a script-only fix using the unchanged bin43 native engine. Restart 3ds Max after installing. Scene data and Edge Border parameter formats are unchanged.
