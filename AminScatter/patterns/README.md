# Density pattern artwork

The picker and installer include three original starter masks: Uniform, Soft patches and Wide bands. They are generated mathematically by Cyrus, with no vendor image inputs. The user can supply a larger final collection later.

The same three images also serve as deterministic qualification fixtures under `tools/density_0862/patterns`. The user explicitly requested installed patterns in the 0.86.2 UI follow-up. Verify product bytes with `python AminScatter/tools/generate_density_patterns.py --output AminScatter/patterns --check`; this is a small starter collection, not the deferred final artwork set.
