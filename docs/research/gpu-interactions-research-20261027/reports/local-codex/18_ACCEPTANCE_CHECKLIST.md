# Acceptance checklist

## Completed in this research

- [x] Answered the shared brief independently and kept the report separate from external A/B/C submissions.
- [x] Inspected current source/preparation/interaction/display boundaries and the Max 2027 public SDK declarations.
- [x] Preserved current static fitting, units, source sharing, independent hiding and failed-successor semantics in the proposed design.
- [x] Distinguished resident instances, active plants, guides/nodes, pairs, vertices and triangles.
- [x] Compared CPU, CUDA, OpenCL and graphics-shader options without presupposing a CUDA speed advantage.
- [x] Executed matched synthetic CPU/CUDA/OpenCL deformation on the same RTX 3090 with full output numerical checks.
- [x] Measured kernel, completed wall and transfer-inclusive windows separately; retained quantiles/build identities and limitations.
- [x] Executed CUDA and OpenCL writes to standalone owned D3D11 buffers with exact D3D readback checks.
- [x] Identified the actual NV OpenCL extension variant and separated it from Khronos support.
- [x] Documented public Max shader buffer/device declarations without claiming unexecuted retained interop.
- [x] Produced sparse-memory estimates, precision policy, async/lifetime proposal and 70-case edge matrix.
- [x] Pinned five upstream implementation repositories, inspected relevant files/licenses and recorded hashes.
- [x] Defined small implementation prototypes, decision gates, failure behavior, CPU fallback and artist workflow.

Package completion checks, file counts and archive identity are recorded by the package validation receipt. This checklist describes the research content; it does not promote proposals into executed product behavior.

## Comparison gates when external reports arrive

- [ ] Preserve received originals and hashes before creating normalized summaries.
- [ ] Separate provided baseline facts from independent inspection and actual execution.
- [ ] Verify every claimed Max integration method in original public documentation/source.
- [ ] Normalize backend benchmarks for algorithm, quality, data layout, transfers, active counts and timing window.
- [ ] Audit memory estimates for per-instance dense guide maps, full vertices and simultaneous generations.
- [ ] Resolve root infeasibility, broad-leaf validation and hiding semantics explicitly.
- [ ] Compare static fitting versus dynamic simulation proposals as different behaviors.
- [ ] Resolve contradictions with a deciding experiment; AI agreement alone does not pass a gate.
- [ ] Write a merged decision only after external evidence is available and reviewed.

The research supports a promising direction and a concrete next experiment. It does not claim unlimited realtime capacity, a CUDA winner, a shipped GPU implementation, or a qualified Max graphics bridge.
