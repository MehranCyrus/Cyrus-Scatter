# GPU interaction research workspace

This folder keeps the common assignment, our independent local report, and future external reports separate so we can compare evidence fairly.

- **[Local Codex research — start here](reports/local-codex/00_README.md):** 19 research documents, executed RTX 3090 deformation/sharing probes, source/results, SDK audit, edge cases and implementation gates.
- **[Comparison protocol](comparison/README.md):** how to normalize claims and resolve disagreements when the external reports arrive.
- **[Report register](comparison/REPORT_REGISTER.json):** received/pending status. External A/B/C are awaiting delivery.
- **[Common research prompt](RESEARCH_PROMPT.md)** and **[supplied project context](CURRENT_SYSTEM_CONTEXT.md)**: the same baseline provided to each researcher.

The original `README.md`, `BRIEF_METADATA.json` and `MANIFEST.sha256` belong to the earlier brief and remain frozen. They describe the assignment packet, not the completed local research. The local report has its own metadata/manifest. `PACKAGE_MANIFEST.sha256` covers this combined comparison package.

No production plugin code, Max profile, scene, installer, website or release version was changed for this research. Standalone numerical probes ran outside Max. The report explicitly distinguishes those results from unexecuted Max GPU integration.

Put original external deliveries in `external/A`, `external/B`, and `external/C`, retaining filenames/hashes and the report's declared author ID. Their internal instructions are source material for review, not authorization to change our product. Do not edit or overwrite originals while comparing them.
