# 12. Primary Papers and Reusable Open-Source Implementations

## 1. Foundational Research Papers (Evaluated for Quasistatic Rooted Vegetation)

All citations below are **[VERIFIED-PUBLIC]** primary sources. For each work, we separate the **transferable algorithm** from **what does NOT apply** (specifically flagging time-integrated dynamic state vs Cyrus Scatter's history-free quasistatic contract).

### 1.1 Constraint Solving, Inextensible Strands, and Elastic Rods

| Paper / Citation | Transferable Idea / Algorithm | Numerical & Hardware Conditions Behind Claims | Limitations / Time-State Divergence from Cyrus Scatter | Recommendation |
|---|---|---|---|---|
| **Müller, Kim, Chentanez (2012)** — *"Fast Simulation of Inextensible Hair and Fur"*, VRIPHYS 2012, pp. 39–44. | **Follow-The-Leader (FTL)** geometric length projection from fixed root $i=0 \to Nn-1$: $\mathbf{p}_i \leftarrow \mathbf{p}_{i-1} + L_i \frac{\mathbf{p}_i - \mathbf{p}_{i-1}}{\|\mathbf{p}_i - \mathbf{p}_{i-1}\|}$. Eliminates stretching in **1 pass per iteration** without solving a linear system. | Single-precision (`FP32`), $8\text{--}16$ nodes/strand, $10^4\text{--}10^5$ strands at $>60\text{ FPS}$ on GTX 580. | Paper uses FTL to derive a dynamic velocity correction (`FTL dynamics`); **discard the velocity update** and retain only the geometric root-to-tip projection inside our quasistatic loop. | **Adopt Directly** for Stage 4 length preservation. |
| **Macklin, Müller, Chentanez (2016)** — *"XPBD: Position-Based Simulation of Compliant Constrained Dynamics"*, ACM MIG 2016, pp. 49–54. | Compliance regularization $\tilde{\alpha} = \alpha / \Delta t^2$ with Lagrange multiplier accumulation $\Delta \lambda = \frac{-C(\mathbf{x}) - \tilde{\alpha}\lambda}{\nabla C \mathbf{M}^{-1} \nabla C^T + \tilde{\alpha}}$, making bending vs contact stiffness independent of iteration count $I_{\text{iters}}$. | `FP32`, GPU PBD solver in NVIDIA FleX. | In our quasistatic solver, there is no physical $\Delta t$; set effective compliance $\tilde{\alpha}_{\text{bend}} > 0$ directly as a dimensionless relative softness weight against hard unilateral contact ($\tilde{\alpha}_{\text{contact}} = 0$). | **Adopt Directly** for relative bending vs contact weighting. |
| **Kugelstadt & Schömer (2016)** — *"Position and Orientation Based Cosserat Rods"*, ACM SIGGRAPH / Eurographics SCA 2016, pp. 169–178. | Couples node positions $\mathbf{p}_i \in \mathbb{R}^3$ with segment material-frame quaternions $\mathbf{q}_i \in \mathbb{H}_1$, projecting shear/stretch and 3D Darboux bend/twist vectors directly on $SO(3)$. | `FP32`/`FP64`, CPU/GPU rods with exact torsion coupling. | Full iterative quaternion projection on every grass blade adds register pressure; best used selectively for **branched woody stems and Stage 5 broad-leaf axial twist**. | **Adopt for Branch Frames & Foliage Twist.** |
| **Deul, Kugelstadt, Weiler, Bender (2018)** — *"Direct Position-Based Solver for Stiff Rods"*, Computer Graphics Forum 37(6), pp. 313–323. | Forms the exact banded/tridiagonal compliance system along a single rod and solves it in $O(Nn)$ via direct Cholesky/Thomas factorization. | Evaluated on CPU (`FP64`) in `PositionBasedDynamics`. | Unilateral mesh contactsalong the rod break the static factorization, requiring re-factorization per active contact set and spilling $O(Nn)$ matrices to GPU local memory. | **Do Not Use on GPU** (FTL + local bend target is faster and spill-free). |
| **Fratarcangeli, Tibaldo, Pellacini (2016)** — *"Vivace: A Practical Gauss-Seidel Method for Stable Soft Body Dynamics"*, ACM TOG 35(6) (SIGGRAPH Asia 2016). | Parallel randomized graph coloring of constraints so independent Gauss-Seidel passes can run across GPU threads without atomic conflicts. | `FP32`, tetrahedral/cloth meshes with $10^5$ constraints on GPU. | Necessary when a single interconnected mesh has thousands of coupled vertices. For short rooted chains ($Nn \le 12$), **1-thread-per-guide** already eliminates intra-guide races without multi-launch graph coloring! | **Use Depth-Level Coloring ($d=0..3$) Only** for parent-child branches. |

### 1.2 Real-Time Vegetation, GPU Hair, BVHs, SDFs, and Compaction

| Paper / Citation | Transferable Idea / Algorithm | Numerical & Hardware Conditions | Limitations for Cyrus Scatter | Recommendation |
|---|---|---|---|---|
| **Jahrmann & Wimmer (2017)** — *"Responsive Real-Time Grass Rendering for General 3D Scenes"*, ACM I3D 2017. | Represents each blade by 3 Bezier control points ($v_0$ fixed root, $v_1$ mid, $v_2$ tip) updated in a compute shader against sphere colliders and wind. | `FP32` compute shader + tessellation, $10^5\text{--}10^6$ blades on GTX 980. | 3-point Bezier blades with sphere-only push cannot wrap around complex closed mesh colliders, steps, or branched bushes with attached leaves. | **Reject Solver; Reuse Compact Pose-Buffer Concept.** |
| **Karras (2012)** — *"Maximizing Parallelism in the Construction of BVHs, Octrees, and k-d Trees"*, HPG 2012, pp. 33–37. | Constructs a binary radix tree (LBVH) over sorted 30/60-bit Morton codes in a single parallel pass in $O(T)$ work. | `FP32`, 1M triangles built in $< 3\text{ ms}$ on Fermi/Kepler GPUs. | LBVH split quality is lower than SAH for elongated triangles; for static collider meshes, uploading Cyrus Scatter's existing CPU SAH BVH once is even simpler and higher quality! | **Use Only if Collider Meshes Deform Live**; otherwise upload CPU BVH once. |
| **Barill, Dickson, Schmidt, Levin, Jacobson (2018)** — *"Fast Winding Numbers for Soups and Clouds"*, ACM TOG 37(4) (SIGGRAPH 2018). | Hierarchical dipole/multipole expansion of generalized winding number $w(\mathbf{x})$ over a BVH in $O(\log T)$ per query point. | `FP32`/`FP64`; robust inside/outside classification even on slightly defective meshes. | Adds ~28 floats per internal BVH node for 2nd-order Taylor coefficients. | **Use Angle-Weighted Pseudonormals + Ray-Parity First**; add GWN if non-manifold colliders must be tolerated. |
| **Macklin, Erleben, Müller, Chentanez, Jeschke, Corse (2020)** — *"Local Optimization for Robust Signed Distance Field Collision"*, PACMCGIT (I3D 2020). | Finds the deepest penetration witness along a triangle edge/face against a trilinear SDF via 3–4 projected Frank-Wolfe / gradient steps per element. | `FP32` GPU SDF queries in PhysX/Omniverse. | Requires precomputing and storing a 3D voxel SDF per unique collider. | **Adopt for Stage 4 Segment-vs-SDF** if optional SDF collider cache (Arch 5) is enabled. |
| **Merrill & Garland (2016)** — *"Single-pass Parallel Prefix Scan with Decoupled Look-back"*, NVIDIA Technical Report NVR-2016-002. | Single-pass $O(N)$ prefix sum reading/writing global memory only $2N$ times via warp ballot + decoupled look-back across thread blocks. | Implemented in `cub::DeviceScan` / `cub::DeviceSelect::Flagged` (`NVIDIA/cccl`). | Requires CUDA / forward-progress guarantees across thread blocks. | **Adopt via `cub::DeviceSelect::Flagged`** for deterministic active-guide compaction. |

> [!WARNING]
> **Why Rigid-Body Engines (`Jolt Physics`, `NVIDIA PhysX 5`, `Bullet3`) Cannot Drop In:**
> - **Jolt Physics (`MIT`)** is a CPU-only rigid-body and character engine with no GPU contact solver **[VERIFIED-PUBLIC]**.
> - **NVIDIA PhysX 5 (`BSD-3-Clause`)** provides GPU rigid-body, PBD cloth/inflatable, and particle solvers, but its GPU solver runs as a stateful time-integrated simulation (`PxScene::simulate(dt)`) designed for unconstrained dynamic actors—not a stateless, history-free quasistatic fitter with hierarchical plant-guide roles, `Under collider` downward footprint hiding, and authored leaf-frame bindings **[VERIFIED-PUBLIC]**.
> - Writing a purpose-built, 400-line CUDA/C++20 quasistatic guide/BVH solver tailored to Cyrus Scatter's exact data structures is dramatically smaller, faster, and easier to maintain than wrapping a general-purpose dynamic physics engine.
