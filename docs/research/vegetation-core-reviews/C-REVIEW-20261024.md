## Rotated-box profile difference

The coordinator's first box positive incorrectly assumed A/B's Euclidean clearance and C's permitted axis-expanded OBB certificate would agree. That failed test is retained. The candidate is physically clear and an independent disjoint-feature distance diagnostic measures approximately **5.155 mm** minimum visible separation against a 5 mm target, but it intersects C's larger conservative envelope. C therefore correctly retains Fail under its declared profile.

The final suite explicitly requires this conservative rejection; it does not publish or relabel the pose as validated. A separate experiment uses **10 mm solver clearance** and validates the resulting mesh against the original **5 mm C target**, which passes. This is an explicit fixture experiment, not an adopted artist default, hidden retry or universal guard-band policy. Solver/validator box profiles still need alignment before product integration.

The SAT overlap proxy can be zero for a planar triangle even when conservative overlap is reported. Acceptance must use the validation status and issues; the number is not a physical penetration-depth certificate.
