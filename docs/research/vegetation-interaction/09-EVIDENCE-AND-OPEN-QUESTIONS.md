# 09 Evidence, corrections and open questions

**Status: consolidated review as of 24 October 2026.** This register governs how claims from the supplied reports should be used. It is a research decision aid, not a record of executed vegetation simulations.

## Evidence categories

| Category | What it establishes | What it does not establish |
| --- | --- | --- |
| Local source inspected | Structure/behavior visible in the recorded files | Loaded build identity, host execution or renderer support |
| Vendor documentation checked | Public feature/control described at the access date | A full assembled scene's success or internal proprietary algorithm |
| Reported example inspection | The research author's account of saved network records/hashes | Independent repetition here or execution in the current DCC |
| Proposed recipe/design | A specific hypothesis with a procedure | Proven reliability, speed or asset coverage |
| Arithmetic estimate | Cost or geometry calculation under stated assumptions | Runtime memory, convergence, application contact or performance |
| Supplied offline check results | R11's stored seven representation and ten evaluator results, with scripts and inputs | Independent repetition of those scripts here, automatic preparation or Max integration |
| Supplied headless execution records | R13/R14 harnesses, reported Linux CPU diagnostics and distinct recorded build profiles | Independent repetition here, Windows/Max behavior, full fitting, renderer output or performance |
| Independent data recount | This update's OBJ/GLB topology counts and archive integrity checks | Botanical identity, a contact result or renderer qualification |
| Cited-source hash checks | R12's eleven local/public files and later supplied ledgers checked against local source after line-ending normalization | The entire dependency, local wrapper lifecycle, binary identity or runtime quality |
| Executed application result | Only an actual run with inputs, build and evidence | Untested variants, later builds or a whole release |

Multiple reports may draw on the same documentation and each other's prompts. Agreement is useful synthesis, not an independent experimental replication.
