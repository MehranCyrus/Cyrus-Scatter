# Evidence, provenance and source identities

All web material below was accessed on 6 October 2026. An undated documentation page is a current documented contract, not proof that every older plugin binary implements it. GitHub files were fetched through the connected GitHub tools and pinned to returned commit references. No repository was installed or executed.

## Evidence labels

| Label | Meaning in this assessment |
| --- | --- |
| VI — directly verified implementation | Current Cyrus source, a fetched integration implementation, or bounded prior disassembly. Does not imply a runtime benchmark. |
| API — documented API/behavior | Author or Autodesk documentation. Describes public behavior/contracts, not an independently verified private implementation. |
| RM — reproduced measurements | Preserved campaign with identified inputs/builds and results. Existing campaigns were audited here, not rerun. |
| EI — engineering inference | A conclusion or proposed design derived from evidence; its practical magnitude needs an experiment. |
| U — unknown | Not established by inspected material or tests. |
