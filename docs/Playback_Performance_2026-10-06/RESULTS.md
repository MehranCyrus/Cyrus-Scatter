## Performance and delivery interpretation

The fix removes unconditional placement/preparation/publication work and recurring settled Analyzer polling. A timeline callback still performs lightweight cached integer/state checks, and the viewport still draws cached objects. Per-frame drawing and GPU limits remain. No presented FPS benchmark, percentage improvement, zero whole-process CPU, unlimited scalability or production readiness is claimed.

Memory changes are transient intervals/counters/owner registries and bounded parent traversal (4,096 ancestors). Native validity is queried on the Max thread at a real dirty/expired input; geometry may be evaluated then. No host SDK calls move to a worker thread, no GPU compute path is added, and no retained upload or snapshot allocation algorithm is rewritten.

Old MZPs and the artist's installed profile are unchanged. A new script needs the matching DLL set; the runner verifies loaded module paths/hashes and the script payload. Native build receipts reject source changes during build/testing and the launcher rejects stale fingerprints. The observed unchanged artist INI is evidence for that file, not a blanket audit of every third-party cache.
