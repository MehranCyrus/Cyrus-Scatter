# Selective Apply Style — 0.85.1 contract

PG05 first supported projection targets one existing logical layer. Select a saved layer and one or more groups: Amount, Grid layout, Transforms, Slope and altitude, Mesh channel mask (including its curve), Density texture, or Area falloff (including its curves). It reads the complete recipe's metadata/settings without hydrating Paint. It does not create a new preset format.

Terrain, models, receiver-bound Paint, layer order, Bands, source/receiver identities and spacing relationships remain owned by the destination. Selected node/map fields require explicit role bindings, including dormant bindings carried by that selected group. The layer's final combination is validated before mutation, so a saved Amount setting incompatible with retained Bands rejects as a whole. Source replacement, Band transfer and Paint Area retargeting are not implicit style operations.

Keep destination seeds is the default. Saved/New apply the population, sampling-salt and model-assignment seeds; receiver variation domains stay with the destination. New draws are fixed in the reviewed proposal and stored by Undo. Saved seeds do not promise identical placements on different terrain or with different source/receiver identities.

The review captures owner reference/ID, recipe hash and saved-layer ID, selected groups, bindings, effective values, controllers, authored settings and the root input key. Commit rejects a changed file, deleted/replaced owner or changed destination, rather than following a later selection. A valid identical Keep apply creates no hold, setters, invalidation or panel rebind. A real change detaches selected scalar controllers where needed, applies the reviewed diff in one hold and performs combined validation. Failure cancels the hold and retains the previous publication. Manual changes wait for Update; Live follows the normal relevant-edit path.

Initial support requires static destination settings and no authored Scatter Edit records/per-instance radius overrides. Selected curve arrays with parameter controllers reject before mutation until their transfer adapter is qualified. Ordinary controller-free curve arrays are supported. These are explicit protected combinations, not discarded data. PG10 remains responsible for authored-data/effect adapters.

Scoped native Max 2027 witnesses now pass same/no-op and changed Apply handlers; preserved complete Paint/receivers/models/identities; role binding, units, shared scalar controllers, stale review, missing owner, protected radius/controller data; failure after setters; and Undo/Redo outside Python's implicit hold. A selected graph's handles are reconstructed in a detached hidden Max curve control and checked against its samples before mutation. An unbound saved dependency rejects even when the binding table explicitly contains an undefined value. See the [candidate ledger](PROGRESS_0851.md) for exact source/host receipts and failed fixture history. Final-pair, broader Live/idle, authored Edit and sustained-use acceptance remain open. This is a candidate, not release qualification.
