## Original version decision and contract

Selected **0.83.0**: a new artist placement feature warrants a minor version.
Independent products are unchanged. Scene schema 58 remains appropriate: new
saved layer fields have neutral defaults and no old field changes meaning.
Native surface-filter capability 1 identifies the added bridge.

F01–F11 apply through the existing layer, candidate, dependency, publication,
bounded work, host thread, cache, geometry, physical unit and persistence contracts.

- Per-layer slope and altitude filters are disabled by default. Slope is the
  angle of the world-space triangle winding normal to +Z: 0 upward, 90 vertical,
  180 downward. Smoothing normals and plant alignment do not change it. Mirroring
  affects transformed winding in the same way as the evaluated receiver geometry.
- Altitude is world Z at the candidate's final receiver anchor, after movement
  and Relax/reprojection, before source pivot offsets and protected Edit movement.
  Unprojected movement uses the stored barycentric plane projection, consistently
  with the existing anchor contract; this does not imply receiver containment.
- Each interval has independent **inside** lower/upper fades. Outside [min,max]
  weight is zero. A zero-width fade includes its endpoint. A positive lower fade
  rises from 0 at min to 1 at min+width using t*t*(3-2*t); the upper fade reverses
  this near max. Crossed/nonfinite bounds, negative widths and overlapping fades
  are errors. Min=max is valid only with hard boundaries. Slope bounds are 0–180.
- Multiply slope and altitude weights, then compare one independent deterministic
  random channel keyed by seed, receiver identity and original candidate ordinal.
  Existing Paint max-union and map/Band density channels are unchanged.
- Filter **after** cached movement/Relax, Paint and source transforms, and after
  Edit replay, but before spacing/cleanup/accepted-target refill. Protected Edit
  rows bypass eligibility. Filter changes stay out of immutable Edit bindings and
  raw candidate cache keys. Filtered rows retain their exact identity/transform.
- Disabled filters do not copy/evaluate receiver geometry. Enabled preparation
  reads bounded evaluated geometry on the host thread and computes each needed
  face slope once. Warm reads reuse the normal prepared/publication path.
- Diagnostics describe prepared-pool eligibility, separately from accepted-target
  attempts/shortfall. They publish atomically with rows and remain old in Manual.

float barycentric components need not sum exactly to one in double precision.

incorrectly compared metre values with Max's automatically converted inches;

an ambiguous negative Scale-property assignment; corrected witnesses use an
assigned closed Path and explicit mirrored transform matrix. These were harness
corrections, not changes to Band or transform behavior.

## Performance and limits

For **20,000 rows on two receiver faces**, the disabled script stage returned the
existing row array without native geometry/allocation: 0–1 ms in Max 2026,
0–2 ms in Max 2027 over 20 runs. Seven enabled-stage measurements were
`9,8,9,7,6,10,7` ms (2026) and `7,8,8,6,6,5,8` ms (2027). One hundred warm
key/publication reads took 2009 / 1478 ms and added no solve, preparation or
receiver builds. Shared-workstation timings include host work, are not pure
kernel time or FPS, and are not a cross-version speed comparison.

The geometric filter is bounded to one million admitted rows and ten million
copied receiver faces, with admission before that face copy. Needed face slopes
are calculated once per invocation. Warm prepared results are reused; this is
not a new persistent geometry cache. The existing conservative parameter
validity system still observes animated parameter controllers, including saved
inactive settings; no new selective animation-dependency optimization is claimed.

Computer Use infrastructure is unavailable, so no physical pointer/DPI/visual
polish pass is claimed. Host callbacks and generated controls were exercised.
Production terrace/renderer output and final physical artist acceptance remain

Test Scene assets, separate products and public site deployment are unchanged.
