samples and editable handles are bounded, with 257 graph points permitting a
lossless samples-only polyline. Density and Paint scale use unit range; other

assignment; animated/wired targets are rejected. Storage is bounded UTF-8 JSON,
validated before same-directory atomic replacement. Browsing performs no solve.

## Performance and limitations

Both hosts ran on this workstation, sometimes concurrently, with small Point or
box fixtures. Scanning 512 valid preset files took 119.78 ms (2026) / 119.39 ms
(2027). The Live readiness witnesses observed the completed successor after
293 / 220 ms, including the 100 ms observer timer; this is not solve time or a
latency guarantee. Each Apply published one complete successor after initial
scene notifications drained. Passive browser/rename and 120 status callbacks
preserved full placement fingerprints, preparation counts and retained uploads.
120 status callbacks took 3900.80 / 1173.88 ms under these concurrent-host
conditions; do not compare these totals as a Max-year speed benchmark or FPS.

The user deferred physical artist acceptance to the end of the eleven phases.
Computer Use infrastructure remains unavailable. Button callbacks, bounds and
model behavior were exercised in real Max; physical pointer/DPI/visual polish,
the Delete confirmation dialog, broad production scenes and renderer output are
not newly qualified by P02. This phase changes settings/curves, not the placement
or renderer kernel. No normal profile, installed 0.81.6 package, original Test
Scene, licensing policy or public site was changed. File replacement was tested
for normal, locked and read-only cases, not power-loss crash durability.
