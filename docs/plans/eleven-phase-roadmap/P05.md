## Original qualified contract and version

Select **0.85.0**, the next minor for a new artist editing workflow. Schema 58 and
the native saved vector format stay unchanged. Add Brush conversion capability 1
and require the matching native/script pair. Other products remain independently
versioned. Apply F01/F04/F05/F06/F09/F10/F11.

- Export one selected Paint Area as one editable spline shape containing closed
  linear contours, including holes/islands. It is an independent snapshot on the
  receiver's **local XY projection plane (local Z=0)**, transformed into the scene.
  This deliberately exports the authoritative vector domain, not approximate
  terrain feedback or a reconstructed stroke history. On terrain it is a planar
  editing guide; the Paint Area continues to use the terrain itself.
- Import one picked evaluated closed spline shape at the current time. Transform
  every Bezier control into receiver-local coordinates and project along local Z.
  Sampling error is measured in the receiver's transformed XY metric, so scales,
  mirrors and shear do not change the meaning of the world-unit tolerance.
  Reuse the existing bounded convex-hull adaptive spline sampler.
- Even-odd fill across all imported loops supports arbitrary winding/order,
  nested holes/islands and self-intersections. Normalize first, then clip to the
  receiver domain. Replace sets coverage; Add unions the normalized imported
  coverage with the preceding region (it cannot erase existing paint).
- One input shape, at most 8,192 input knots and 8,192 sampled vertices. Existing
  vector output limit is 200,000 vertices and 0.0001 local-unit quantization.
  Tolerance must exceed that quantization's transformed positional error floor.
  Reject open, degenerate, nonfinite, unsupported and excessive inputs before
  editing. A valid closed shape outside the receiver can replace with empty
  coverage. Error messages explain the required repair.
- Commands require a valid explicit area/receiver and a stopped brush. Preserve
  area identity, density/falloff, sources and source spline. One Undo per command;
  a no-op import adds no document revision. Manual retains its published result;
  Live follows normal area invalidation. No implicit live links, subscriptions or
  new general curved-surface Paint support. Export itself does not edit coverage.
- UI: Export spline; import Replace/Add choice; world-unit Curve tolerance; Pick
  spline. Capture owners before selection/control changes. Tolerance is an import
  command option, not a placement key or a saved dependency on the source shape.
