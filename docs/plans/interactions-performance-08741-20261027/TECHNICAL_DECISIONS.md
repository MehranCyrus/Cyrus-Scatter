# 0.87.4.1 interaction campaign: implementation decisions

These decisions describe the candidate under qualification, not a promise that every asset or physical configuration is supported. See the [investigation](INVESTIGATION.md) and final delivery evidence for measured scope.

## Ownership and invalidation

- A prepared source remains shared and immutable. Its cached reconstruction can be reused only when the saved-definition hash, source watch and validity interval, units, settings, collider mode and validated rig agree. A cache miss takes the existing admission path. Source edits and changed definitions must not silently reuse stale bindings.
- Each placed plant retains its own transient pose, fixed-root mask and root-frame choice; instances with different rotations and scales do not share a pose. Nothing in this change adds a saved-scene field or changes schema 62. Undo continues to own authored source/proxy references and placement edits.
- Removing a source removes its unreachable preparation and custom-proxy link inside the existing Undo transaction. In Manual mode the previous complete publication stays available until Update; it is not relabelled as a newly evaluated result. Malformed binding tables remain untouched and need explicit repair.
- The immutable collider index describes the published layout. A separate bounded index represents edited successor positions; overridden and disabled original entries are excluded. Candidate IDs are sorted and rechecked against exact bounds before fitting, and failure cannot mutate the previous publication. Global collider admission is 16,384; the separate limit of 64 relevant colliders for one plant and the 4,096 transient-edit limit remain.

## Geometry and quality

Fixed-root occupancy and triangle contact use bounded predicates equivalent to the former signed-distance/bounded-distance questions. Triangle bounding boxes and conservative plane separations reject provably distant pairs; a proved hit can finish early. Solid parity and strict contact-band semantics are retained, with fixed-size traversal and a bounded-by-mesh fallback for unusually many ray crossings. Independent full visible-mesh validation still uses the original distance calculation. Tests include random faces, nested closed shells, actual captured boulder geometry and recorded plant contacts; no approximate sphere substitutes for the stone.

The candidate also checks fixed edges and fully fixed faces of an active root when their bounds overlap a collider: a surface can cross a solid even when every anchored vertex and the root centre lie outside it. A confirmed crossing is an explicit fixed-root conflict, or hides that rooted group only when the artist has enabled root hiding. It is not inferred from a conservative stem envelope. These on-demand scans and contact queries count against the existing per-pose work and classification budgets; they create no persistent per-instance geometry. The saved source remains shared, and a failed or exhausted check retains the previous complete result. Controlled edge-only and face-interior cases and a captured grass-root replay exercise this policy; final Max host qualification is tracked separately.

The hinge search asks only whether a candidate capsule is clear. Its new bounded segment predicate can prove clear or blocked without constructing full surface witnesses. A conservative interval accounts for the admitted near-similarity transform error and coordinate roundoff; borderline cases use the existing witness equation. The full collision API and final actual-mesh checks still use their original witnesses. Query admission, cancellation, bounded collectors and work limits remain enforced. Unit tests compare the decision against the previous witness across multiple shapes, scales, large offsets, boundary distances and cancellation/resource limits, plus a captured boulder. The performance and retained-pose comparisons are specific to the recorded workload and do not establish visual or presented-frame performance.

A preferred planted hinge is derived from root-adjacent topology. If its independently checked mesh exhibits substantial local edge distortion, the fitter can compare a shorter hinge and an alternative continuous root frame. An alternative is adopted only if its actual mesh clears the colliders and its measured same-guide stem-edge change improves. This optional comparison shares the existing per-pose work ceiling and can be skipped when the budget is insufficient; all guides continue through the ordinary contact process. The selected frame is carried consistently to the visible mesh, attached foliage, child guides and normals. This improves captured cases but does **not** prove every leaf remains below the 25% audit threshold or that visually acceptable deformation follows from that percentage alone.

When the optional per-guide edge measurement finds a change above 25%, the candidate carries that warning with its immutable pose and aggregates it across the currently published poses. The Interactions status points the artist to **Check full visible mesh**. The diagnostic reports how many guides were actually checked; it does not assert that unchecked guides or the complete mesh passed. Restoring an unchanged pose or removing a contact also updates the warning with the retained publication, and no new scene field is serialized.

## Work and memory

An attempted Live-mode shortcut for a collider-only Edit transform was discarded. The interaction renderer and gizmo can show a moved collider using transient overrides, but the immutable procedural publication, snapshot readers and MCP page API would still contain its old transform if the placement rebuild were simply skipped. The experiment was restored to the sealed candidate source hashes. A future optimization must atomically publish matching placement, contact, renderer and readback generations; distinguish collider-only transforms from structural and other edits; fall back whenever rules, filters or other dependencies require a solve; and verify Undo/Redo and save/reopen. This work is not implemented in 0.87.4.1.

Large automatic interaction updates may use up to eight numeric participants, leaving two logical processors available on machines with more than four when possible. Small jobs retain the existing automatic limit. An explicit session CPU-thread override takes precedence; ordinary scatter keeps its prior policy. Workers consume copied immutable data, and ordered merging/publication remains on the host thread. Query and exact-mesh scratch reservations scale with the selected participant count; admission reduces participants before exceeding the existing 512 MiB layout/index/query reservation. Pose payload retains its existing separate limit. These are accounted reservations, not total Max process, allocator or GPU peak memory.

The next candidate distributes affected plant jobs dynamically among those bounded participants because guide and collision complexity vary. Each job still writes its own slot in sorted input order, and the ordered merge selects failures and poses in that same order. If worker launch fails, the existing joined serial fallback resets the job cursor and recomputes every slot. The atomic cursor has constant storage; worker scratch admission is unchanged. Captured pose comparison and full host qualification are recorded separately.

Reported `worker_*_ms` measurements are sums over worker activities, so they may exceed elapsed `fit_ms`. They are diagnostic CPU work, not frame time or FPS. Full visible-mesh auditing and exact per-triangle validation can remain expensive on dense assets. Real-time movement is a workload-dependent result, not guaranteed for all model counts, shapes or nearby guides.

## Remaining boundaries

The current contact system supports positive uniform instance scales; mirrored, sheared or nonuniform similarities require a separate implementation and qualification. A fixed root embedded in a collider cannot be bent out while its anchor remains fixed; root hiding or moving the collider is an explicit choice. Open/nonmanifold collider meshes need a valid proxy. Tea Tree - 03 currently needs guide and attachment repair beyond higher limits. Timeline wind, dynamic simulation and automatic detailed tree-root colliders are not delivered by this static contact fitter.
