# Invalidated scripted navigation probe

The files named `navigation-final08-nav-smoke.json` and `presentmon-nav-smoke-summary-v2.json`, and an earlier baseline script with the same approach, were initially labeled as programmatic viewport movement. The fixture uses a Top orthographic view. Autodesk's [Max 2027 documentation](https://help.autodesk.com/cloudhelp/2027/ENU/MAXScript-Help/files/MAXScript-Tools-and-Interaction/Interacting-with-the-3ds-Max/Viewports/GUID-8AA71F9E-F4F0-4437-A44E-9683619E89DE.html) states that `viewport.setTM` operates on Perspective views. The script did not check its return value, so those measurements do **not** establish a moved camera, navigation performance, or navigation invalidation behavior. They are retained as test-driver history and excluded from acceptance.

The separate physical mouse-wheel run produced a changed view and checked the placement/retained counters around real input. Its own restoration attempt also used `setTM`, which is unsupported in that view; the current test driver reports that limitation instead of claiming restoration. The reported wheel measurement is one observed view and is not used as a matched camera comparison.
