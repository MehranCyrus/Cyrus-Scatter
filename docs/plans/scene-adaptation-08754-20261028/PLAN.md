## Geometry, scale and response

Reacting plant transforms retain the existing positive-uniform requirement.
Obstacle transforms have a separate boundary: bake a finite nonsingular linear
transform into an internal immutable collider copy, leaving scene objects and
rendered transforms untouched. Translation-only changes reuse the copy. General
rotation/stretch changes may rebuild that bounded numeric shape, but must not
recapture/reprepare plant sources or regenerate placements.

The broader response uses bounded guide/envelope checks and angle proposals,
not the detailed per-vertex refinement loop. Preserve branch attachment points
and inherit accepted parent transforms. Protect a structural trunk/root guide
which owns children; an obstructed fixed structure remains visible with a
diagnostic, rather than failing the whole response. Bend mode can retain an
uncleared branch and reports it; it makes no exact-contact guarantee.

Pruning is a per-instance visibility decision on a whole prepared guide subtree.
It is not arbitrary polygon slicing or a new capped cut surface. Clearance and
penetration threshold choose eligible branches; a deterministic amount selects
which eligible branches hide. Rest-source geometry stays shared, and moving an
obstacle away restores visibility. Rendering and Bake must consume the same mask.
Topology without reliable branch/leaf ownership needs review; the feature must
not claim to reconstruct every welded commercial tree automatically.

Neighbors use prepared branch representations and spatially filtered pairs.
Stable layer/candidate identity resolves which tree yields when both opt in;
queries use rest geometry to avoid cyclic feedback and flicker. This directional
priority is an explicit adaptation policy, not symmetric rigid-body physics.
Trunk placement collisions remain the ordinary spacing system's responsibility.
