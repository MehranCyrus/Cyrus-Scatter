## Earlier delivery: Max 2027 camera export/import — 0.1.1

The user authorized the standalone Max 2027 exporter, app import and complete workflow testing. Browser/exporter/player advance independently from private 0.1.0 to **0.1.1**, because sampled camera segments add a persisted/public playback contract. Camera-bearing projects use **project schema 2**: source inspection showed that an old schema-1 autosave reader could silently strip an unknown clip reference and play an ordinary path, so a version guard is necessary. Existing ordinary schema-1 author projects remain readable. Public manifest version 1 now requires playerVersion 0.1.1; the separate closed camera file format is version 1. Native Scatter/Analyzer/MCP and website versions are unchanged. This is not publication readiness.

[Exporter and usage](../../../presentation-studio/tools/max2027/README.md): run [CyrusCameraExporter.ms](../../../presentation-studio/tools/max2027/CyrusCameraExporter.ms) through **Max 2027 > Scripting > Run Script**; no installation or restart. Choose a native Free, Target or Physical camera, range and 1×/2×/4× sampling (4× default), export JSON, then **Project > Import camera animation…** in the studio. The exporter reads evaluated world transforms, including parents, target/path constraints and roll, and native evaluated FOV including Physical focal length/zoom/focus breathing. Positions convert Max Z-up/system units to canonical Y-up/metres; FOV converts horizontal to vertical using render pixel aspect. A matching landscape scene origin is required. Landscape root changes do not rebind the camera.

Imported motion uses original sample timestamps, linear position/FOV and shortest-path quaternion interpolation, with zero automatic endpoint holds. It starts after the existing plan/reveal introduction and never enters the ordinary Bézier arc-length/easing evaluator. The clock uses elapsed time across slow frames rather than clamping elapsed intervals to 100 ms; hidden tabs still pause. Source data are immutable SHA-256 resources; only active clips stay decoded, while history retains their original bytes. Limits are 4 MiB/file, 20,000 samples/clip, 100,000 unique active samples/project and one hour, with finite pose/FOV/aspect validation before publication. Orthographic, shifted/tilted/distorted or mirrored/nonuniform/sheared camera setups and third-party camera classes are explicitly rejected. Cuts and renderer-specific appearance/clipping/DOF/motion blur are outside this movement/lens contract.

A bounded review precedes one undoable journey replacement. Two endpoint cards and a single imported segment keep the UI compact; source pose/lens/path/speed controls are read-only. Scrub, reverse and **Use frame in viewport** preserve the imported pose. Capture then appends an ordinary editable view; Remove animation explicitly restores an editable straight endpoint path and is undoable. Imported resources survive autosave, portable save/reopen, actual compiled preview, replacement from that preview, and a separately served public ZIP. Missing resources fail visibly instead of substituting a Bézier motion.

## Implemented behaviour

The local single-admin studio imports static self-contained GLBs, converts root units/up axis, assigns hierarchical nodes to independent presentation layers, edits root transforms, calibrates a plan and reviews explicit replacement mappings. Asset revisions, layer IDs, camera stops and travel segments have stable identities. Prepared successors commit atomically; failures retain the old complete scene. History preserves immutable originals and applies one command per gesture.

Explore and Plan are temporary editor cameras. Capture/Update creates or changes an authored stop. The shared deterministic evaluator handles arbitrary/reverse seeks, holds, adaptive arc-length Bézier travel, normalized quaternion interpolation, portrait variants, fitted framing, monochrome-to-colour and per-layer reveal/fade. The public player uses native scroll, stop buttons, keyboard, play/pause, restart and reduced motion. Viewer visibility is session-only and never regenerates placements.

Imported artistic images require explicit approval for a SHA-256 scene/pose/framing fingerprint. Timing-only changes retain approval; scene/pose/lighting/default-visibility changes stale it. Images appear during holds, yield to 3D during travel or viewer visibility mismatches, and fall back to 3D on delayed/failed decode. A bounded plan/current/next-image cache releases superseded URLs, including resources retired during asynchronous loads.

Local autosave uses an atomic IndexedDB committed pointer and an owned OPFS blob directory where writable, otherwise IndexedDB blobs. Portable archives preserve original resource bytes and authored state. ZIP directory/path/count/expanded-size checks precede allocation; CRC, lengths, hashes, schema, GLB admission and image decode checks precede activation. Packing/import runs in cancellable owned workers. One heavy job is admitted; an edit invalidates stale job completion.

Compilation prunes excluded GLB nodes/resources, strips private source labels/extras, emits a content-addressed public manifest and packages the prebuilt player. Compiled preview runs that same built entry through a checked origin/source/token protocol; it suspends the editor renderer. Public output contains no studio controls, editable archive, originals, history, source maps, API secrets or remote service dependency. Missing/corrupt 3D input or absent WebGL2 retains available plan/artistic navigation and disables unavailable 3D layer controls.

Rendering preserves imported instancing, geometry sharing and culling. Static scenes render on demand. Actual WebGL bufferData/bufferSubData calls are counted. Sources and cloned instance buffers have separate accounting and disposal; old/new resource headroom is checked. Balanced/Mobile and hysteretic render-scale changes preserve authored density, positions, layers and timing. Optional asynchronous GPU queries do not start an idle polling loop.

Deferred scope is unchanged: procedural planting/set generation, density/region/mask/terrain editors, per-plant editing, cloud/authentication services, collaboration, generation providers and commercial licensing.
