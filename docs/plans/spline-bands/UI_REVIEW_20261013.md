## Finding and correction

The reported sequence was independently reproduced in a fresh owned Max 2027
scene using the previous delivered script `7a92c0b1…925c4`: clicking Clusters
did not change Random mode. Two hidden managed Band list controls retained
visible native rollout hosts at screen rectangles (1528,296,146,58) and
(1528,296,146,71). They overlapped Clusters and Spline bands; Analyzer lay below.
Hiding just those native hosts immediately made the same Clusters click work.

The generator now synchronizes both managed visibility and native host visibility
for colored lists and resize grips. It checks the actual WS_VISIBLE style before
sending a visibility change; a collapsed parent must not mask a child host's style.
This follows Autodesk's [documented Windows methods](https://help.autodesk.com/cloudhelp/2026/ENU/MAXScript-Help/files/Interaction-With-The-Operating/GUID-282F32AC-5A80-4FDB-B8C0-275D2CC15845.html).
It covers inline, container and floating generated views and runs on layout,
not pointer movement. All authored settings and internal identities are retained.

Permanent help paragraphs were removed from Surfaces, Source containers, Models,
Layout, Amount, Painting and other settings panels. Redundant generated headings
and the verbose Workflow disclosure were removed. Controls, counts, pending/error
states, brush feedback and Analyzer status remain. Radius-mode guidance moves to
its tooltip. Artist documentation and website changelog are aligned locally.

## Measured comparison

The corrected original 0.79.5 installer from `dist/refinement-0.79.5-creation`
was extracted into an isolated profile with matching original binaries. Its script
hash is `cacf3e6b1af8796d96bca7ed2698cfb762d3baff7f90bc35a507b100ee0af4b4`.
Neither version loaded the other's scene format. Each created the same primitive
workload: three layers, 10,000 candidates per layer, one 500-unit plane with 8x8
segments, Box/Sphere sources, fixed seeds, no enabled spacing. Max 2027 was used
for both. Timed workloads ran sequentially; other desktop activity was not locked.

| Synchronous host operation | 0.79.5 | Corrected 0.80.0 |
| --- | ---: | ---: |
| First calculation | 201.1 ms | 264.6 ms |
| Unchanged explicit Update (median, 7) | 19.0 ms | 18.6 ms |
| First Modify mount | 9136.9 ms | 6678.8 ms |
| First Models + Layout bind | 1020.8 ms | 1217.7 ms |
| Warm Models + Layout bind (median, 10) | 683.3 ms | 167.3 ms |
| Warm Random/Clusters switch (median, 10) | 650.8 ms | 126.0 ms |
| Point navigation (median, 20) | 29.3 ms | 15.3 ms |
| Mesh navigation (median, 20) | 5.4 ms | 2.9 ms |
| Save | 1297.5 ms | 421.9 ms |
| Load | 3182.6 ms | 2704.1 ms |
| Changed seed Update (median, 9) | 146.8 ms | 232.1 ms |


Warm UI binding/switching improved substantially. First construction still takes
seconds. Changed calculations are slower in this sample: approximately 58% in the
seed-edit median and 32% in the single cold solve. The first two-panel bind also
increased in its single sample. These are unresolved performance findings, not
evidence that every recent change improved speed. No risky solver shortcut or
old compatibility path was added to conceal them. Follow-up profiling should
separate preparation, paired-radius transport, validation, publication and preview
costs, then rerun the exact workload before claiming an improvement.

Both versions performed zero solves, candidate preparations, preview rebuilds or
retained-buffer uploads during the measured warm Point/Mesh navigation. Current
Manual edits retained the last complete publication; unrelated Live edits did
not rebuild it. Source inspection confirms keyed candidate reuse and the bounded,
validity-aware source-geometry cache. Current publication stages its successor
before swapping generations; 0.79.5's original method reset its old generation
before allocation. Retain the newer correctness guarantees when tuning performance.

Timings are synchronous host calls, not presented FPS. Cold entries are single
observations. Heavy artist scenes, every DPI, renderer and GPU/device-loss case
are outside this comparison; prior qualified native/runtime behavior is not
recertified wholesale by UI tests.

## Attempts and limits

The first generator write failed once with a filesystem error; retry succeeded.
An intermediate unguarded native-visibility variant completed its checks in both
hosts, but the 2027 client timed out before the host returned success. Its receipt
was retained, pending work allowed to finish, and only those owned hosts closed.
The final guarded variant completed the 55-assertion 2027 fixture in about 30 s.
An initial physical check on a programmatically opened/remounted view did not
establish acceptance. Final physical checks use actual rollout-header input in
fresh Live scenes. All receipts and intermediate files remain available under
`build/ui-first-click-review-20261013-01` and the named profiles.
