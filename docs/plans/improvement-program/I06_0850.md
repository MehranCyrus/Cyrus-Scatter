## Artist workflow

In **Layout > Planting positions**, choose Surface random, Rectangular, Staggered or Hexagonal. Rectangular has independent column/row distances. Staggered offsets alternating rows by half a column, including negative rows. Hexagonal exposes the nearest-neighbor distance; row pitch is calculated. Set an explicit world X/Y origin, heading and optional stable jitter. Grids project vertically onto the highest surface of each receiver.

The origin does not follow terrain bounds or masks. Pitch sets available population; Count/Density and accepted-target/refill settings are inactive. Paint, Include/Exclude, mesh/UV masks, slope/altitude and collision rules thin those positions. They do not refill missing cells. Random mix, Clusters and Spline Bands still choose sources independently. Analyzer Single/EdgeRow supplies its own positions and is rejected with grids. Entirely vertical receivers cannot receive vertical grid projection.

The setup admits at most one million enumerated candidates across its layers, including grid cells over holes. Excessive sparse bounds, invalid projection or missing mapping fail while retaining the previous complete publication. Each native receiver projection also has triangle, scratch-memory and query-work bounds; these are per receiver, not a new process-wide cache budget. Changing a bound grid frame with authored Edit/radius data requires the existing explicit reset/restore workflow.

The **Rectangular orchard** example contains 35 regularly placed trees and 2,200 groundcover plants. **Hexagonal hillside planting** demonstrates hex spacing, surface projection and normal blending. Both use permitted procedural geometry, actual-result PNG thumbnails and matching editable scenes. Six examples are now bundled; the four original recipe/scene/thumbnail sets remain unchanged. See [inventory and use](../../../AminScatter/library/README.md).

## Implementation and persistence

The native projector uses copied evaluated triangles and a bounded 2D triangle hierarchy. Highest world-Z wins; exact-height ties use the lowest evaluated face index. Candidate anchors enter the existing assignment, transforms, filters, Paint, Edit, final-radius and spacing pipeline. Host access stays on Max's thread. Grid snapshots contain no retained node pointers and are immutable GC-owned values.

Cell IDs encode mode, persistent receiver slot and signed lattice coordinates in a disjoint positive 64-bit family. They are not bounding-box ordinals or hashes. Original Surface random identities and default binding text remain unchanged. Expanding terrain preserves common cell identities and unrelaxed attributes when other inputs match; topology changes may change face/barycentric fields and invalidate authored geometry bindings.

Scene schema stays 58 with an appended seven-field block. Complete recipes advance to **4**, numeric presets to **3**, grid capability to **1**. Strict earlier-format reads add neutral Surface random settings without rewriting originals. Grid distances obey both recipe unit conversion and numeric preset metre storage. See [format contract](FORMAT_4.md) and [implementation contract](I06_GRIDS.md).

Grid cache keys include evaluated geometry, exact generator settings, required UVs and variation. Downstream orientation and masks reuse the projected snapshot. Inactive Count/Density/refill animation is excluded from grid dependencies; inactive grid settings are excluded from Surface random. The first host tests caught both an unqualified script owner lookup and unnecessary Count-animation invalidation; both were corrected and rerun.
