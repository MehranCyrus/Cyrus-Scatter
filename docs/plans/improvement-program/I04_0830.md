## Use

Open **Transforms > Orientation** on a selected layer:

- **Random** keeps the established random orientation behavior.
- **World direction** aims the source's Forward axis along the XYZ vector. The vector is a full 3D heading; its length does not matter. At least one component must be nonzero.
- **Look at target** aims from each final candidate position toward a picked object's world pivot. The object's rotation and shape do not define the heading.
- **Align to normal / Normal %** controls preferred up. Disabled or 0% uses world +Z; 100% uses the evaluated geometric face normal. Intermediate values follow an angular blend. In direction modes, this controls roll while keeping the heading.

Models use local +Z as up. Set each model's **Forward axis** in Models & Points (+Y, -Y, +X or -X). Local random XYZ rotations still apply, so zero their ranges when checking exact aim. A target directly above/below a plant is valid; a coincident pivot uses the Random reference frame. Parallel heading/up uses a deterministic alternate up. This is geometric face alignment, not smoothing-group/interpolated normals. Slope/altitude eligibility remains independent.

Direction follows final candidate movement/Relax and Paint scaling, then existing source offsets, CS Edit and final radius/spacing rules apply. In Random mode, Analyzer boundary facing retains its existing authority. Explicit direction modes override that facing. Normal alignment now follows the final face after Relax crosses a face; this is an intentional correction to the earlier pre-Relax normal.

Manual edits wait for **Update scatter**. Live responds to relevant target/parent movement and orientation animation. Missing targets or a zero world vector report a failed update and retain the last complete publication. Editing target geometry or rotating it around an unchanged pivot does not recalculate scatter.
