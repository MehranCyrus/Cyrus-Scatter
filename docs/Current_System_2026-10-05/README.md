## Historical 5 October conclusion

- **Plugin:** local 0.7.1 source has the floating Layer Editor, procedural policy 3, source containers, Brush, Edit/radius integration and retained previews. It is a development candidate. Existing installers are a different snapshot.
- **Known failure:** Corona Interactive Rendering repeatedly restarted in the user's test session. Production renders succeeded in the earlier real-scene campaign. The initiating callback is not isolated. A separate false Pending status was reproduced; their relationship is not established.
- **Diagnostics:** the recorded baseline has a manually started performance recorder, selected edit traces, runtime counters and a bounded MCP journal. New recorder/export source appeared independently during the vendor recheck; it is not qualified by this report. The full everyday timeline/archive specification remains an acceptance target.
- **MCP:** the recorded 1.1.0 baseline has nine tools/four resources. Concurrent 1.2.0 source now registers a tenth tool, `scatter_read_diagnostic_events`, for an explicitly shared trace; its new host behaviour is unqualified here. Plans 1/2 retain their bounded writes; policy 3 still lacks a write contract. See [coverage](CAPABILITY_MATRIX.md) and the follow-up receipt for the snapshot distinction.
- **ML:** design research and record contracts exist. Style-profile software, reference interpretation, dataset collection, trained inference and automatic learning do not. Diagnostic logs are not artistic preference labels.
- **Licensing:** the native/local experiment has substantial recorded tests, but ordinary builds do not enable it. Complete commercial enforcement and service delivery remain separate release work.

## Evidence discipline

Use **source fact**, **recorded test result**, **current observation**, **hypothesis**, and **proposal** explicitly. A passing SDK build is not an interactive Max test. A test count is not complete feature coverage. A generated image is not proof of the underlying placement state. Current parameter values, pending edits and the last complete publication must remain distinguishable.

No production code, artist scene/profile, installer or licensing state is changed by this documentation task. No commit, push, package or runtime diagnostic activation is part of it.
