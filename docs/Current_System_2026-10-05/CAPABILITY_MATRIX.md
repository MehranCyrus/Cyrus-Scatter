# Native and MCP capability coverage

Reconciled 17 October 2026 for **Scatter development source 0.85.4 / MCP 0.73.0**, calculation model CyrusUnified1, saved schema 58. The [artist guide](../ARTIST_GUIDE.md) describes current ownership; [memory evidence](../plans/memory-0854/README.md) and [ready-preset evidence](../plans/preset-gallery-improvements/LOAD_0853.md) separate scoped qualification from remaining limits. Historical receipts do not establish blanket acceptance.

There is one procedural model. Old scene policies and MCP plans 1/2 are retired and rejected, rather than reinterpreted. The **closed plan 0.73** ports the previously useful bounded authoring subset into that model. It does not expose every native field. Native availability, catalog help and cached inspection do not grant remote mutation authority. Current [server registrations](../../CyrusMCP/cyrus_mcp/server.py), [settings](../../CyrusMCP/cyrus_mcp/settings.py), [schema](../../CyrusMCP/cyrus_mcp/plan.schema.json) and [passive recipe reader](../../CyrusMCP/cyrus_mcp/procedural.py) define the actual boundary.

The [generated semantic inventory](../../AminScatter/tools/ui/layers-control-inventory.json) has **296 controls**. Scatter Modify and selected-container Modify reuse these definitions. The historical [CONTROL_PORT_RESULTS.csv](../Unified_System_0.73_2026-10-06/CONTROL_PORT_RESULTS.csv) accounts for the earlier 245 controls, including merges and moves. Counts are source coverage, not exhaustive behavioral qualification.

## Budgets and evidence

Design enrollment remains at most three mesh sources, three regions/layers, 2,000 aggregate requested candidates, two successful applications and two captures, with 24 ordinary calls per scope and specific outcome/retry recovery exceptions. Native ten-population capacity is distinct from the 32-entry inspection guard. Container reads cap 32 references and 1,024 registered rows per set; presentation strings are bounded. Native source following caps the whole captured hierarchy at 1,024 nodes and ancestor traversal at 64.

Plan size is 32 KiB, context 64 KiB; capture long edge 1,536 pixels and base64 payload 2 MiB. Execution-record export is exactly 1,500,000 bytes. Journal retains 128 records. Publication paging has 2,048 attempts per enrollment, including failed/stale host attempts. Design site/assets retain explicit triangle/vertex and static-controller admission checks.

Do not carry limits into a new feature by assumption or evade them through repeated enrollment. Use [the 0.73 results](../Unified_System_0.73_2026-10-06/RESULTS.md) for exact source/binary campaigns. Offline tests, mocked lifecycle checks, API-driven Max fixtures, actual pointer behavior and presented-frame measurements are different evidence classes. [Prior R&D findings](../TyFlow_CyrusScatter_RnD_2026-10-06/FINDINGS_AND_ROADMAP.md) remain open unless explicitly resolved in the new roadmap.

Band scale profiles: Off, Follow Density or an independent Custom curve. The curve multiplies the existing random Band scale, keeps keyed candidate randomness, and participates in current schema 58 and native Band interface 9. Remote mutation authority is unchanged.
