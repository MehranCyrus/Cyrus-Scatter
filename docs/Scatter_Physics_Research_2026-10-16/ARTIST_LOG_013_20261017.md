## Assessment and recommendation

The crash-prevention guard is doing its intended job in this recording, but the
one-stroke-at-a-time lifecycle is a poor fit for continuous spraying. It is a
current Physics Lab design restriction, not a requirement imposed by rigid-body
physics. Simply removing the guard would be unsafe: the native session also
closes emission after mouse-up, and the previous null-read path must stay guarded.

Recommended future behavior: keep one live native simulation session while brush
mode is active; mouse-up ends only the gesture, and subsequent gestures can add
bodies while earlier bodies move. Define explicit Finish/Freeze and Cancel
actions, stable body/gesture IDs and Undo boundaries. Add an explicit policy for
bodies lost below the relevant colliders so they do not keep an entire session
unsettled; do not treat merely leaving the picked receiver as proof a body should
be discarded when another legitimate collider could support it. Measure solver
progress against elapsed time while keeping per-callback work bounded.

This is a recommendation only. No continuous-brush implementation or unrelated
Scatter/preset work was performed for this log review.
