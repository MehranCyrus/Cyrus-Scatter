## Remaining findings and limits

1. **P1 qualification finding: the first cold container Undo lost its stack.** In final `real073-ui-assets08`, actual Move carried all three shrubs by 415.795 cm and Undo restored them, but both Undo/Redo names were empty and Ctrl+Y did nothing. This repeated an earlier first observation. The failing receipt is retained as `pointer-container-first-redo-failed.json`; a subsequent controlled Move/Undo/Redo/Undo passed and its callbacks recorded a valid Redo entry. The cause is **unisolated**, not a fix claim. The native restore path is `source_container.cpp:192`; the global script Undo refresh starts at `AminScatterObject.ms:12199`. Neither is proven to be the flushing caller. Next acceptance: reproduce the first gesture after fresh load with native flush reason, callback/heap identity and no intervening setup mutation, then preserve previous history and repeated Redo without artificially increasing the artist heap or disabling Undo. This limits release confidence despite the passing controlled regression.

   A subsequent separate cold-load test performs whole-node Move, waits for host messages, Undo, waits, then Redo in distinct requests. It passes exact frame/all-three-source restoration (`cold-undo-result.json`). This narrows the problem but does not qualify the first actual mouse/keyboard gesture. A temporary observer's missing global declaration was corrected before that measurement; its callback error was a fixture fault.
2. **High-count Proxy drawing remains expensive.** Cached box triangles are still submitted on redraw. The 100k mode measures draw cost, not a placement rebuild. Use Point Cloud and sensible display budgets for huge populations. A retained Proxy implementation needs its own draw-only experiment, exact geometry/budget equivalence and unchanged navigation/upload checks before changing the engine.
3. **Material fidelity is partial.** Seven Missing_TextureMap placeholders were captured in the supplied original's private copy **before** the generated garden was loaded, affecting grass and lavender. They also remain in the garden. Ordinary bitmap and CProxy paths resolving does not establish every material plugin; the available data does not identify their original vendor class or establish availability in the normal artist profile. Actual Corona scheduling passes are separate from visual fidelity. The campaign does not guess replacement maps or silently remove warnings.
4. **Worst-case preparation remains open.** Earlier independently reproduced projection scaling, extreme-radius broad-phase selectivity and aggregate wide-Brush derived-state budgets remain useful R&D. Preserve deterministic IDs, exact collision reasons and previous complete publication while addressing those specific paths.
5. **Qualification is finite.** Max 2026 runtime, docked Corona IR, long artist sessions, all DPI/tablet combinations, all 240 pointer fields, other renderers and adversarial Brush sheet/topology cases remain separate gates. Presented timing does not guarantee unlimited FPS. Whole-host RAM/VRAM is not exclusive Cyrus allocation.
6. **MCP, ML and licensing have explicit boundaries.** Native help covers all feature families, but callable writes remain the closed locally approved plan subset. No remote Brush/container/Edit/Analyzer/render authoring or trained reference-image composition model is invented. Commercial licensing remains incomplete and default-off.

## Intermediate evidence interpretation

Earlier stress navigation/playback attempts used invalid source weights or a triangle cap above the supported maximum; their cached fallback results are excluded. An overlapping diagnostic request was a private single-slot transport error; clients now serialize and correlate replies. An initial Corona interface lookup used the wrong object. Fixed three-second cleanup/stop sampling was too early; final tests observe actual cleanup completion, settle, then enforce a strict quiet window. These are fixture corrections, not claimed renderer engine fixes.

One first pointer Brush Undo observation did not remove its stroke after an explicit Update. Isolated Undo-stack checks showed Update preserved the Undo entry, and the subsequent controlled pointer gesture/Undo passed. That first observation remains unisolated; it is not presented as a product defect that was fixed.

In the final pointer rerun, the initial Brush counter baseline preceded the cold native mount and pending preview refresh from the preceding Undo. Its ready flags were false and generation advanced during the first gesture. After explicit Update and a separate ready/warm baseline, Paint/Stop left the epoch, preparation and preview counters unchanged, added one two-sample stroke, and keyboard Undo restored the five original strokes. The unsettled receipt is retained separately. This is a corrected measurement boundary, not evidence that every Manual Undo path is idle.
