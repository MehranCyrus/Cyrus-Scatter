## MCP acceptance

The server registers **12 tools and seven resources**. Plan **0.73** is a closed schema with locally reviewed approval, scoped IDs/revision/digest, idempotency, owned Undo and rollback. Plans 1/2 are retired. The integrated private panel scenario exercises real stdio → IPC → Max main-thread execution, denial, repeated request, refinement, rollback and fresh save/reopen. The direct scenario exercises four display modes and passive reads.

Reading a catalog is help, not mutation authority. Container creation/movement, Brush authoring/history, source-instance Edit, Analyzer bindings, render execution, arbitrary scene save and image training are not public MCP tools. Do not make repeated enrollments to evade bounded scope. Native ten-population capacity and inspection limits are not the design authoring budget.

## Test quality

Fixtures assert identities, exact transforms/radii, bounded behavior, cache/upload counts, error retention and actual Undo outcomes. Intermediate failures are retained. Important improvements to the tests include separate compilation of dependent MAXScript, strict request matching, serialized diagnostic clients, valid source weights/triangle budgets, and explicit matching DLL checks. The new whole-node fixture deliberately avoids `cyrusContainerGesture`; it would fail the earlier implementation despite its native build and simulated helper passes.

The actual pointer tests still matter: the scripted helper suite passed while the Move tool left plants behind. A successful build, a control count, a cached fingerprint or a synchronous redraw measurement alone cannot certify the artist interaction.
