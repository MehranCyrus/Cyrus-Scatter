## Investigated failures

Intermediate receipts do not qualify this pair. Final passes follow these diagnosed corrections:

- The delivered `ee0061...` script reproduced `mainUI`/undefined during natural container selection. Child rollups routed an undefined owner before mounting; earlier tests manually mounted the panel and missed asynchronous errors. Production now captures each view's panel and guards readiness/reentrancy, unlinked enable changes and closed timer callbacks. The independent selection gate is required for packaging. Exact reproduction and earlier identities are preserved in the [correction folder](../Container_Selection_Fix_0.73_2026-10-06/README.md).
- The new selection fixture needed explicit expansion-event dispatch (setting `.open` alone does not call its handler), restoration after a simulated cold transition, the production dropdown dispatch function, and returning to Modify after scene reset/load. A separate reopen diagnostic distinguished expected cold preview-owner creation/initial upload from passive UI work. The final baseline warms the reopened scene with nothing selected; subsequent selection/browsing changes no measured calculation or upload counters. These fixture failures are recorded; none required changing the frozen correction.

- Helper rollout context switching failed because an external function used implicit MAXScript `this`. Production captures explicit `view` on open; shared/inactive/global-no-layer contexts now pass.
- A read-only old-scene probe reproduced Max continuing file load after an `on update` exception, relabelling the old Scatter record as serialization 54. Production now persists a schema-validity denial and guards calculation/publication/copying. The retirement test verifies denial after save/reopen. All current acceptance campaigns were rerun on that final guarded script; the earlier 0.73 package is superseded.
- An old idle fixture expected raw embedded-record writes to request autonomous redraw. The current fixture uses actual UI handlers and explicit redraw for direct map/failure injections. Passive sampling never forces Update.

- The additional Analyzer fixture initially used resolution 32 below the supported minimum 48, then an outside-border band on a receiver exactly equal to that boundary. These were invalid test assumptions. Correct inside-border/edge cases pass positive source choice and persistence checks.
- One concurrent private Max startup exited with `4294967295` before the script bootstrap. Its UI acceptance did not run. The failure stays recorded; subsequent qualification runs serially on unchanged bits. The startup cause is not established.
