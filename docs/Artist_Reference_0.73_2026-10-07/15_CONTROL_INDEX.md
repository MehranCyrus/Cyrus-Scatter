# 15. Complete control index

[Guide contents](README.md)

Use this list to find the explanation for a control. It accounts for all 240 entries in the current Scatter control inventory. Alternate views and four disclosures now folded into Advanced are included, so this is not a claim of 240 separate visible buttons.

Minimum and maximum fields are listed separately here and explained together in their chapter. Matching display labels in different sections do different jobs; use the section heading to identify the right one.

All entries have been checked for an explanation. This is a documentation checklist, not a record that every click has passed a new test.
